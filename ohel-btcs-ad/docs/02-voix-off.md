# 2. Voix off finale — prête à enregistrer

**Voix :** française, naturelle, assurée, chaleureuse et posée. Débit naturel, **sans accélération** : ≈ 181 mots, ≈ 75 s de parole.
**Prononciation validée par OHEL :** « OHEL » se dit **« O-L »** (deux lettres : « ô – èl »).

Conventions : `/` = respiration courte · `//` = pause marquée (≈ 0,5 s) · **gras** = appui léger.
« BTCS » se dit toujours lettre par lettre : **« B – T – C – S »**. Les pourcentages se disent en entier (« soixante-cinq pour cent »).

---

**[A — Accroche]**
Votre prochain projet / commence **ici**. //
Avec la terre… / et la **précision**. //

**[B — Identification]**
**B – T – C – S.** /
Des blocs de terre comprimée / et stabilisée. //
Produits et commercialisés en Côte d'Ivoire / par **OHEL International**. //

**[C — Formulation]**
Tout commence par une formulation **précise**. /
Chez OHEL : **soixante-cinq pour cent** de latérite, / une terre riche et résistante, /
**vingt-cinq pour cent** de sable, / pour la compacité et la texture, /
et **dix pour cent** de ciment, / comme liant et stabilisateur. //

**[D — Mélange]**
Les composants sont soigneusement mélangés, /
jusqu'à obtenir un mélange **homogène**. //

**[E — Compression]**
Le mélange est placé dans le moule de la presse hydraulique. /
Sous forte pression, / il est **compacté**, /
pour former des blocs solides / et réguliers. //
La précision / prend **forme**. //

**[F — Cure]**
Après le démoulage, / place à la **cure humide**. /
Les blocs sont arrosés régulièrement, /
pour favoriser le développement de leur résistance /
et limiter le risque de fissures. //

**[G — Applications]**
Maison, / école, / bâtiment durable : /
les BTCS s'adaptent à vos projets de construction. //
Faites le choix de la **solidité**… / et de l'écologie. //

**[H — Conversion]**
Votre projet mérite des matériaux **bien fabriqués**. //
Pour vos approvisionnements en BTCS, / faites confiance à **OHEL International**. /
Demandez votre **devis**. //
OHEL International : / bâtir **solide**, / bâtir **vert**.

## Consignes d'enregistrement

- Enregistrer en une seule prise continue (WAV 48 kHz / 24 bits), puis livrer une piste mixée `public/audio/voix-off.wav`.
- Prévoir aussi une prise séparée de la signature finale, pour l'ajuster au carton sans retoucher le reste.
- Laisser 0,3 s de silence en tête. Ne pas compresser le temps pour « tenir » une durée : c'est l'image qui s'adapte (voir README, § Minutage).
