# Script voix-off — MTN Côte d'Ivoire
### « Ta connexion Internet finit trop vite ? Voici comment économiser tes données mobiles ! »

Format TikTok 9:16 · 45 s · français · tutoiement
Ton : chaleureux, énergique, complice, pédagogique (grand frère / grande sœur qui donne le bon plan). Débit ~2,5 mots/s, sourire dans la voix.

> La vidéo livrée (`deliverables/mtn-data-ad-tiktok.mp4`) est la **version sans voix-off** (musique + effets sonores). Ce script est calé sur son minutage et peut être enregistré par un comédien puis mixé, ou synthétisé.

**Total : ~110 mots ≈ 40 s de parole**, ce qui laisse respirer la musique et les effets sonores.

## Texte brut (pour le comédien ou la synthèse vocale)

```
Ta connexion Internet finit trop vite ? … Pas de panique : voici comment économiser tes données mobiles !

Astuce numéro un : coupe les mises à jour automatiques sur les données mobiles. Tes applis se mettront à jour en Wi-Fi.

Deux : empêche les applis qui ne te servent pas de tourner en arrière-plan. Garde seulement l'essentiel.

Trois : baisse la qualité des vidéos. En 480p, tu regardes ton match… et tu consommes beaucoup moins de data.

Quatre : surveille les sauvegardes automatiques. Tes photos restent protégées… mais seulement en Wi-Fi.

Cinq : jette un œil à ta consommation pour voir quelles applis épuisent ta connexion.

Et toi, tu connais forcément quelqu'un dont la connexion finit trop vite… Partage-lui l'info !
```

## Notes de mixage
- Baisser la musique de ~8 dB sous la voix (ducking), la remonter sur la fin (00:43–00:45).
- Garder audibles les clics d'interrupteur (00:08,6 · 00:14–00:15 · 00:21 · 00:26,8) : ils ponctuent les « coupe », « empêche », « baisse ».
- Prononciation : « Wi-Fi » = *ouifi* ; « 480p » = *quatre cent quatre-vingts pé* ; « data » = *data*.
- Mentions MTN, slogan ou offre commerciale à ajouter seulement après validation par la marque.
